# SONATA Mobile (protótipo)

App React Native (Expo) do perfil Administrador. Telas: Login, Dashboard, Alunos, Matrícula de aluno (Horários e Professores são placeholders).

```bash
npm install
npm start          # Expo Go / simulador (tecla w abre a versão web)
npm run build:web  # gera dist/ para hospedar
```

Login de demonstração: admin@exemplo.com / admin123. Dados: mock local em `src/data`. Hospedagem e migração para Supabase: `docs/PLANO-HOSPEDAGEM-E-BANCO.md`.
